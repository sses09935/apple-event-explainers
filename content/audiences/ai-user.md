# AI 使用者版

閱讀目的：以日常工作與 Apple 裝置使用情境理解功能，保留 AI 使用者版的識別。
閱讀順序：先讀 intelligence 的官方任務畫面，依需求進入各產品主題；不把 AI 留成硬體表格的附錄。
必要主題：手機影像與雙螢幕、兩款手錶、耳機、AI 的語言／地區／設定與推出條件。
選材：情境、型號差異、設定檢查與需求比較；說明性例子須標明不是官方展示或本人實測。
避免：每個產品硬加 AI、無證據的推薦、把語言清單或藍牙連接當全功能保證。
Developer 延伸選材：只取能幫助理解輸入、輸出、資料缺口、語言與動作完成狀態的內容；技術細節轉成可觀察的使用條件，不列完整 API 清單，也不把文件對照冒充新品實測。
價格選材：先比較功能與使用條件，再讀台灣官網價格、配置與公告日期；影片原始卡片保留自己的市場限制。
