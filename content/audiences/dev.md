# 開發者版

閱讀目的：從已核對功能示例、硬體與使用條件建立整合問題，分清產品規格、公開 API、SDK availability 與 runtime 能力。
必要主題：iPhone 18 Pro 與 iPhone 18 Pro Max、iPhone Duo、Apple Watch Series 12、Apple Watch Ultra 4、AirPods 5，以及 AI 條件。先看功能用途及操作畫面，再讀 API 資料模型、session 流程與必要配置；版本和產品相容性分開。
選材：規格列與註腳、直接相關 Developer 原文；保留權限、配件、格式、OS 與測試前提。
避免：以 Apple 自家功能推導第三方相容、把舊 API 當新品 API、未編譯範例冒充可執行成果。
價格選材：設備規劃可對照台灣官網價格、配置與公告日期；與影片歷史卡片分開，不替代 API 與 runtime 的核對。
